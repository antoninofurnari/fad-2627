# Fundamentals of Data Analysis — lecture notes

Lecture notes, slides, schedule and self-assessment for the course *Fondamenti di Analisi
dei Dati* (BSc in Computer Science, University of Catania), A.Y. 2026/27, taught by
[Antonino Furnari](https://antoninofurnari.github.io/).

**Read them at <https://antoninofurnari.github.io/fad-2627/>.**

## The notebooks

`notes/` holds every chapter as a Jupyter notebook, the same version the "Open in Colab"
button at the top of each page opens. They read the course datasets straight from the
site, so they run on Colab with nothing to download and nothing to configure.

## Contributing

Found a mistake — a typo, a wrong formula, a broken link, code that does not run, an
explanation that is unclear? Please
[open an issue](https://github.com/antoninofurnari/fad-2627/issues/new) saying which
page and what is wrong. Suggestions are welcome too.

Both branches of this repository are generated: the compiled site is rebuilt on
`gh-pages` and the notebooks here are rebuilt on every update, so pull requests cannot be
merged. An issue is the way to reach the notes.
